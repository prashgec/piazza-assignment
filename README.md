# Piazza Assignment

Advanced Cloud Computing coursework: a discussion platform backend built with
FastAPI, Pydantic, SQLAlchemy and SQLite, with JWT bearer authentication.

The assignment covers topic-based posts, reactions, comments and post expiry,
automated testing with pytest, Docker containerisation, and deployment to
Google Kubernetes Engine.

This repository currently contains only this README. Application files, tests,
and deployment configuration will be added in subsequent development stages.
